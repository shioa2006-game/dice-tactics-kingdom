## 検出した問題と修正

- フォーカス時、`overflow:hidden` の盤面がブラウザ標準スクロールで `scrollTop=204` になり、操作部がずれた。盤面を `overflow:clip` に変更。回帰試験でスクロール位置0、盤面ツール下余白9pxを確認した。
- 部隊一覧上のホイールとキーが盤面操作へ伝わる経路を遮断。攻撃可能な駒の「!」表示を補い、控えめ演出でも画面外CPUへ即時カメラ移動するよう修正した。
- 最初の360試験では、移動を戻す処理の確定直後に前フレームの描画キューを読んで「待機へ戻る」が失敗した。試験側に描画フレーム待機を加え、3サイズとも65/65になった。[初回の記録](../screenshots/qa-360-first-run.json) も保持。ゲーム状態や期待値は変更していない。
